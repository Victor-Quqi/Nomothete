# Nomothete

Nomothete 是一个软件项目命名工具，在本机运行，通过浏览器使用。它根据项目描述生成候选名字，提供取义说明，并查询包名、GitHub 仓库和域名的使用情况。名字是否合适由用户评价。

Nomothete 一词取自柏拉图《克拉底鲁篇》中的 νομοθέτης，意为"立名者"。

## 安装与启动

需要 Node.js 24 或更高版本，以及模型服务的 API 密钥。

```bash
npx nomothete --open
```

首次启动时填写 API 地址、模型和密钥，地址和模型可以留空，默认使用 DeepSeek。服务启动后会打开浏览器，默认地址为 [http://localhost:5179](http://localhost:5179)。之后可以在界面左下角的"设置"中修改，也可以重新执行设置：

```bash
npx nomothete --setup
```

使用 `--port` 指定端口，使用 `--verbose` 开启请求日志：

```bash
npx nomothete --port 7000 --verbose
```

默认仅允许本机访问。通过 npm 安装或使用 npx 启动时，模型配置和会话数据保存在 `~/.nomothete/`。已保存的 API 密钥在设置页面中仅显示末四位。模型服务和其他设置见[配置说明](./docs/configuration.md)。

也可以从源码启动：

```bash
git clone https://github.com/Victor-Quqi/Nomothete.git
cd Nomothete
npm install
npm start
```

从源码启动时，模型配置和会话数据保存在项目目录。

## 使用方法

新建会话，填写项目描述。可以补充已有的名字作为参考，并标记喜欢或不喜欢。生成时会采用词根组合、典故、旧词等不同方法，每个候选都附有取义说明。

用 `▼▼ ▼ · ▲ ▲▲` 表达对名字的评价，五档由不喜欢到喜欢，中间为未定。评价和备注会影响后续生成，评价可以修改或撤回。按 `t` 查看系统从当前会话中推断的偏好及其依据。

按 `p` 调整生成时参考的取名偏好，例如是否倾向容易拼写和发音的名字。每条都可以单独开启或关闭，并附有证据强度、依据和不适用的情况。

候选会按模型估计的罕见程度筛选，可通过"罕见度下限"调整。下限越高，筛选越严格。被筛掉的名字不会再次出现，点底栏的"丢掉 N 个"可以查看，并把想要的留下。

"再来一批"旁边的箭头可以为这一批写一句方向，或者指定取名方法。在详情中可以照某个名字再来一批，新名字会沿着它的来源、读音或角度另找路子。

候选默认按生成批次显示，较新的批次在前，同批次按产生顺序排列。可以搜索名字和取义说明，按评价、取名类别、批次或查重结果筛选，也可以按模型估计的罕见程度或检查发现的问题数量排序。

会话会自动保存，支持重命名、置顶和删除。导出的 Markdown 包含候选名字、评价、备注和检查结果。

## 名字检查

| 检查内容 | 执行时间 |
| --- | --- |
| 是否符合 npm、PyPI、crates.io 的包名要求 | 生成后 |
| 是否与本地已记录的包名重复 | 生成后 |
| npm、PyPI、crates.io 是否有同名包 | 生成后 |
| npm 搜索中出现的相关包 | 生成后 |
| 不同拼写是否会被包发布平台视为同名 | 标记为 `▲` 或 `▲▲` 后 |
| GitHub 上包含该名字的仓库 | 标记为 `▲` 或 `▲▲` 后 |
| `.com`、`.dev`、`.io` 域名的注册记录 | 标记为 `▲` 或 `▲▲` 后 |

"查无记录"表示本次查询没有找到对应记录。实际发布时仍由各平台判断是否接受该包名。

标记为 `▲` 或 `▲▲` 后，还会自动联网核查取义说明中的词义和来源。发现矛盾时会在候选卡片上提示，详情中列出具体说法、资料摘录和来源链接。尚未确认的内容列为"待查证"，可以继续通过浏览器搜索。导出文件会保留核查结果和来源。

在设置中可以关闭取义核查。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `j` / `↓` | 选择下一个候选 |
| `k` / `↑` | 选择上一个候选 |
| `1` 至 `5` | 设置评价，对应 `▼▼ ▼ · ▲ ▲▲`，然后选择下一个候选 |
| `u` | 撤回上一次评价 |
| `Shift+J` | 选择下一个未定的候选 |
| `Enter` | 查看详情 |
| `n` | 编辑备注 |
| `s` | 朗读名字 |
| `c` | 复制名字 |
| `g` | 生成下一批 |
| `Shift+G` | 写方向、挑方法，再生成一批 |
| `f` | 照选中的名字再来一批 |
| `e` | 导出 Markdown |
| `/` | 搜索候选 |
| `t` | 查看当前会话的偏好 |
| `p` | 调整取名偏好 |
| `⌘K` / `Ctrl+K` | 打开命令面板 |
| `?` | 查看快捷键 |
| `Esc` | 取消选中或关闭面板 |
